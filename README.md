# هی تب 🎙️

یه دستیار صوتی فارسی برای تبلت Galaxy Tab A7.
همیشه گوش می‌ده؛ می‌گی «**هی تب**»، بوق می‌زنه، بعد دستورت رو می‌گی.

---

## نصب (فقط یه بار)

### ۱) ساختن اپ
1. برنامه‌ی **Android Studio** رو از سایت رسمی نصب کن.
2. توش `Open` رو بزن و پوشه‌ی `HeyTab` رو انتخاب کن.
3. صبر کن Gradle همه‌چیز رو دانلود کنه (بار اول چند دقیقه طول می‌کشه).
   - اگه به‌خاطر محدودیت‌های شبکه دانلود قطع شد، باید از یه آینه‌ی (mirror) Maven/Gradle که برات در دسترسه استفاده کنی.
4. روی تبلت: `Settings > About tablet > Software information` و هفت بار روی **Build number** بزن تا Developer options فعال بشه. بعد توی `Developer options` گزینه‌ی **USB debugging** رو روشن کن.
5. تبلت رو با کابل به کامپیوتر وصل کن و توی Android Studio دکمه‌ی ▶ (Run) رو بزن.

اگه کابل نداری: `Build > Build APK(s)` رو بزن، فایل APK رو به تبلت منتقل کن و نصبش کن (باید نصب از منبع ناشناس رو اجازه بدی).

### ۲) مدل تشخیص گفتار فارسی
اپ برای فهمیدن صدا از **Vosk** استفاده می‌کنه که کاملاً آفلاینه.
1. از صفحه‌ی `alphacephei.com/vosk/models` مدل **کوچیک فارسی** (حدود ۵۰ مگابایت، اسمش چیزی شبیه `vosk-model-small-fa-...`) رو دانلود کن.
2. فایل zip رو به تبلت منتقل کن (نیازی به باز کردنش نیست).
3. توی اپ «هی تب» دکمه‌ی **انتخاب فایل مدل فارسی** رو بزن و همون zip رو انتخاب کن. خودش بازش می‌کنه.

### ۳) مجوزها (توی خود اپ سه تا دکمه داره)
- **میکروفون و اعلان**: ضروریه.
- **نمایش روی برنامه‌های دیگه**: فقط برای دستورهای «باز کن» و «جستجو کن» لازمه (اندروید اجازه نمی‌ده سرویس پس‌زمینه بدون این مجوز اپ باز کنه).
- **بهینه‌سازی باتری**: خاموشش کن تا سامسونگ سرویس رو نکشه.

### ۴) شروع
دکمه‌ی **شروع گوش دادن** رو بزن. یه اعلان ثابت میاد؛ این لازمه، چون اندروید برای گوش دادن مداوم میکروفون همین رو می‌خواد.
بعدش بگو: «**هی تب**» ← بوق ← دستورت.

---

## دستورها

| بگو | چی میشه |
|---|---|
| «ساعت چنده؟» | ساعت رو می‌گه |
| «تاریخ امروز» / «امروز چندمه؟» | تاریخ شمسی و روز هفته |
| «تایمر پنج دقیقه» / «تایمر نیم ساعت» | تایمر می‌ذاره و آخرش زنگ می‌زنه |
| «تایمر رو لغو کن» | تایمرها رو پاک می‌کنه |
| «صدا رو زیاد کن» / «صدا رو کم کن» / «صدا رو قطع کن» | صدای تبلت |
| «یوتیوب رو باز کن» | برنامه رو باز می‌کنه (کروم، دوربین، تنظیمات، گالری، تلگرام، اینستاگرام، واتساپ، نقشه، ماشین‌حساب و…) |
| «جستجو کن هوای تبریز» | توی گوگل سرچ می‌کنه |
| «چه کارایی بلدی؟» | لیست کارها |

برای اضافه کردن دستور یا برنامه‌ی جدید، فایل `CommandHandler.kt` رو ببین. لیست برنامه‌ها (`aliases`) بالای فایله و اضافه کردنش خیلی ساده‌ست.

## جواب صوتی فارسی

اپ از موتور «تبدیل متن به گفتار» خود اندروید استفاده می‌کنه. تبلت‌های سامسونگ معمولاً فارسی ندارن. اگه فارسی نصب نباشه:
- جواب‌ها به‌صورت متن توی اپ و یه پیام کوتاه نشون داده میشه،
- و فقط بوق می‌شنوی.

برای داشتن صدای فارسی: `Settings > General management > Language > Text-to-speech` رو ببین و موتور گوگل رو نصب/انتخاب کن و داده‌ی فارسی‌ش رو دانلود کن (اگه برای دستگاهت موجود باشه).

---

## اتصال به هوش مصنوعی (اختیاری)

اگه سوالی بپرسی که جزو دستورهای بالا نباشه، اپ می‌تونه سوال رو به یه سرویس هوش مصنوعی بفرسته. پایین صفحه‌ی اپ سه تا چیز رو پر کن: آدرس پایه، کلید API و اسم مدل. سرویس باید API با فرمت `chat/completions` داشته باشه. اگه خالی بذاری، فقط دستورهای محلی کار می‌کنن.

کلید توی حافظه‌ی خود اپ ذخیره میشه و جای دیگه‌ای نمی‌ره، به‌جز سرویسی که خودت واردش کردی.

---

## تغییر کلمه‌ی بیدارباش

توی `ListenService.kt` مقدار `WAKE_PHRASE` رو عوض کن. کلمه‌ها باید جزو واژگان مدل فارسی باشن، پس بعد از تغییر امتحانش کن.

---

## محدودیت‌های صادقانه

- مدل کوچیک فارسی بعضی وقت‌ها اشتباه می‌شنوه؛ توی اتاق ساکت و نزدیک میکروفون بهتر جواب می‌ده.
- ممکنه گاهی با صداهای شبیه «هی تب» اشتباهی بیدار بشه، یا اولین بار نشنوه.
- گوش دادن مداوم باتری می‌خوره؛ بهتره تبلت به شارژر وصل باشه.
- اگه تبلت ریستارت بشه، باید اپ رو دستی باز کنی و «شروع» رو بزنی.
- این کد توی محیط من کامپایل و روی دستگاه واقعی تست نشده. اگه موقع بیلد خطایی دیدی، متنش رو برام بفرست تا درستش کنم.
